# sshm v3.0.0

## 更顺手的默认工作台

- 无参数启动不再自动进入全屏选择器，默认显示与 `h` 相同的快捷命令页。
- `p` 打开主机选择器，`k` 进入托管密钥中心，`host` 进入主机管理中心。
- 新增交互式批量添加主机，以及校验通过后才更新的 `config-edit`。

## 主密码保护的托管密钥

- 支持自定义密钥名称、默认密钥、批量生成与导入。
- 托管私钥只保存在主密码加密的 `secrets.yaml` 中，不以明文长期写入磁盘。
- 普通连接、远程执行与 ping 直接在内存中使用托管密钥。
- 支持批量绑定、推送、验证、撤销与删除，目标可按别名、分组、标签或全部主机选择。
- `key setup` 仅在公钥推送并验证成功后修改主机绑定。

## 健壮性

- 公钥推送可重复执行，不会重复追加；撤销仅删除目标公钥。
- 批量远程操作默认 4 并发，并逐台输出成功或失败原因。
- 托管密钥删除会拒绝仍被主机使用或仍为默认项的密钥。
- 旧版手写配置缺少 `port` 或 `auth` 时会自动补齐默认值。
- 旧版明文密钥命令和现有配置继续兼容。

## 升级说明

- 无需手动迁移现有 `hosts.yaml` 或 `secrets.yaml`。
- 首次创建托管密钥会新增 `keys.yaml`，私钥内容写入现有主密码加密库。
- Linux 发布包继续使用纯 Go 静态构建，不依赖目标机器的 glibc。
