# sshm v2.3.0

这一版把重点从继续增加安全机制转向日常使用体验：更少提问、更快找到主机、更自然的命令。

## 更快连接

- 无参数启动进入实时主机选择器，支持输入过滤、上下选择和回车连接。
- 新增 `pick`，可随时重新打开选择器。
- 新增 `pin`、`unpin` 和 `recent`，收藏常用主机并查看最近连接。
- 成功连接后自动记录最近使用时间。

## 更顺手的管理命令

- 支持 `sshm add/list/edit/search/...` 子命令，同时兼容旧版 `--add/--list/...`。
- 支持快速添加：`sshm add prod root@example.com:2222`。
- 添加向导不再默认询问 SSH 密码；只有选择 `password` 认证时才询问。
- 编辑可选字段时输入 `-` 即可清空。
- 未知选项会提示最接近的正确命令。

## 更清晰的查找与展示

- 搜索支持多个关键词，以及 `group:prod`、`tag:web` 过滤器。
- 主机列表根据终端宽度自动切换布局，支持 `--compact`、`--wide`、分组过滤和排序。
- 分组和分组内主机使用稳定顺序展示。
- `copy` 生成的 SSH 命令会包含已配置的密钥参数。

## 辅助能力

- 新增 bash、zsh、fish 自动补全脚本。
- 新增 `doctor`，检查配置路径、系统 SSH 和失效密钥路径。

## 升级说明

- 配置会自动从 v2 升级到 v3，以保存收藏状态和最近连接时间。
- 旧命令参数和现有主机配置继续兼容，不需要手动迁移。
