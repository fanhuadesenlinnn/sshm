# sshm v4.1.0

## 标签管理

- 新增独立的 `sshm tag` 管理中心，支持标签创建、备注、查看、重命名和删除。
- 支持按主机、现有标签或全部主机批量添加、移除、替换和清空标签。
- 标签定义与主机引用继续保存在唯一的 `sshm.yaml`，所有关系修改均原子完成。
- 标签列表增加使用统计、备注、示例主机和未分类主机入口。

## 日常使用

- `sshm list` 新增默认、`--compact` 和 `--wide` 三种视图，并根据终端宽度自动调整。
- 默认视图隐藏端口 `22`、空列和常规认证字段，连接目标更加紧凑。
- 远程 Shell 主动退出或返回非零状态时，不再误触发临时密码认证。

## 配置

- `sshm.yaml` 新增 `tags.items` 一级标签定义；已有主机标签会自动登记。
- 仍然只使用一个配置文件，不生成 `.bak`。
- 首次使用新版本时无需手动迁移配置。
