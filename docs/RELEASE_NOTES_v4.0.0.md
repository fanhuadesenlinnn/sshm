# sshm v4.0.0

## 单文件配置

- 所有主机、默认值、主机信任、托管密钥元数据和加密 vault 统一存入 `sshm.yaml`。
- 配置使用文件锁、临时文件、`fsync` 和原子替换，不再生成 `.bak`。
- 默认配置带简短编辑提示；`strict`、`accept-new`、`insecure` 可全局设置或按主机覆盖。
- v4 不迁移旧版多文件配置，旧文件会被忽略。

## 安全连接

- 连接、ping、执行、密钥操作、转发和传输共享同一认证、主机信任与单级跳板机实现。
- `insecure` 仅在配置中显式启用时跳过主机身份验证，并持续显示警告。
- 已配置认证失败后，交互连接可以尝试一次临时密码；只有明确批准才保存。
- 新增原生本地端口转发，不透传任意 OpenSSH 参数。

## 批量操作与传输

- 远程操作统一展示逐主机失败阶段、原因、建议和重试命令。
- 批量操作日志按操作和主机保存，默认保留 30 天。
- 推送和拉取支持文件、目录、特殊字符路径、默认拒绝覆盖和临时目标启用。
- 适用时使用安全受约束的 `rsync` 加速，否则自动回退原生 SFTP。

## 安装与升级

模块路径升级为：

```bash
go install github.com/fanhuadesenlinnn/sshm/v4@latest
```

这是不兼容旧配置的主版本升级。升级前请自行保留旧数据目录；v4 会创建新的 `sshm.yaml`。
