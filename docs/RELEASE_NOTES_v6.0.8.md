# sshm v6.0.8

v6.0.8 改进了手工配置主机、批量凭据管理和长命令交互体验，不改变 v6 主配置或 Deploy schema，不需要迁移。

## 新增

- `passwd` 和 `forget-pass` 支持多个主机、`--tag` 与 `--all`；批量密码更新在同一个配置与加密 vault 事务中完成，避免部分写入。
- 手工在 `sshm.yaml` 中新增主机时可省略内部稳定 ID；配置校验通过后 sshm 会自动生成并原子写回，菜单仍保持原有数字 ID 显示。

## 修复

- 修复交互模式粘贴超过终端宽度的长命令时，整条命令反复刷屏的问题。输入行现在使用单行水平视窗，不再依赖终端自动折行后的多行清理。
- 新增 bracketed paste 处理，整段粘贴只重绘一次；粘贴内的换行作为空格插入，不会提前执行半条命令。

## 质量

- 补充手工配置自动补 ID、非法配置不重写、批量密码原子性、批量删除密码、长行视窗、多行粘贴和 FC 远端命令引号保真的回归测试。
- 现有批量托管 Key 选择与远端操作保持不变。

## 升级注意

- 主配置和 Deploy 配置仍为 `version: 2`。
- 从 v6.0.7 升级到 v6.0.8 不需要修改配置文件。
- 已有主机的内部 `id` 用于关联凭据，仍不应手工修改；仅手工新增的主机条目可以省略 `id`。
